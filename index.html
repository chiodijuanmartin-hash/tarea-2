Promises, Async y Await

Actividad 2 · JavaScript asíncrono

¿Qué vamos a aprender?

Las Promises permiten trabajar con resultados futuros. Las palabras clave async y await ayudan a escribir ese código de forma más fácil de leer y entender.

1. Async y Await

function obtenerPuntaje() {
  return new Promise(resolve => {
    setTimeout(() => resolve(85), 700);
  });
}

async function mostrarPuntaje() {
  const puntaje = await obtenerPuntaje();
  return `Tu puntaje es ${puntaje}`;
}

mostrarPuntaje().then(console.log);

¿Cómo funciona en palabras simples?

La función obtenerPuntaje simula una operación que tarda un poco y después entrega el número 85.

async declara una función asíncrona. await espera el resultado de una Promise dentro de esa función antes de continuar.

Dicho de forma natural: “Esperá a que llegue el puntaje y después armá el mensaje”.

La espera no bloquea toda la aplicación: JavaScript puede continuar atendiendo otras tareas mientras llega el resultado.

2. Controlar errores

async function cargarPerfil(falla = false) {
  try {
    if (falla) {
      throw new Error("No se pudo cargar");
    }
    return "Perfil cargado correctamente";
  } catch (error) {
    return `Ocurrió un problema: ${error.message}`;
  }
}

cargarPerfil().then(console.log);
cargarPerfil(true).then(console.log);

¿Cómo funciona en palabras simples?

El bloque try contiene la operación que queremos intentar. Si ocurre un error, el control pasa a catch.

throw genera un error de ejemplo para demostrar qué sucede cuando algo sale mal.

Dicho de forma natural: “Intentá cargar el perfil. Si no podés, capturá el problema y devolvé un mensaje”.

Así podemos responder a los fallos de manera controlada en vez de dejar errores sin manejar.

3. Promise.all

const tarea = (nombre, tiempo) =>
  new Promise(resolve => {
    setTimeout(() => {
      resolve(`${nombre}: listo`);
    }, tiempo);
  });

async function iniciar() {
  const resultados = await Promise.all([
    tarea("Perfil", 700),
    tarea("Mensajes", 1000)
  ]);

  return resultados;
}

iniciar().then(console.log);

¿Cómo funciona en palabras simples?

Se crean dos tareas simuladas: cargar el perfil y cargar los mensajes. Cada una tarda un tiempo diferente.

Promise.all espera a que todas las Promises terminen correctamente y devuelve sus resultados en una lista.

Dicho de forma natural: “Empezá las dos tareas y avisame cuando las dos estén listas”.

Si alguna Promise falla, el resultado de Promise.all también falla. Por eso es importante planificar el manejo de errores.

Conclusión

Async y await hacen que el código basado en Promises sea más fácil de leer. Try/catch permite controlar errores, y Promise.all ayuda a esperar varias operaciones asíncronas.
